# digital_design_diagrams

This repository builds `digital-diagrams`, an agent skill for drawing digital-system
diagrams (gate level, RTL, FSM/ASM, timing diagrams, register maps, datapaths,
microarchitecture, SoC and interconnect) that are correct, unambiguous, readable, and
consistent with academic and industry conventions.

Work in progress. The skill, its documentation, and its evaluation are being built on
the `skill-build` branch.

## Repository policy

- `material/` holds copyrighted source books and standards and is never committed.
- `work/` is scratch space and is never committed.
- Only generated, original content is tracked: the skill, templates, evaluation cases
  and outputs, and documents written in our own words.
